# 环球旅行指南(离线版)

一个纯前端的全球旅游指南:**文字 + 插画为主,可语音播报,视频以链接提供**。无需安装、无需服务器,下载后断网也能用。

## 内容

- 17 个热门目的地:日本、韩国、泰国、巴厘岛、阿联酋、土耳其、法国、意大利、西班牙、英国、埃及、摩洛哥、肯尼亚、美国、秘鲁、巴西、澳大利亚
- 每个目的地包含:概览、最佳出行时间、必去景点(配插画)、特色美食、交通、实用贴士、常用语(可跟读)、视频搜索链接
- 「出行通用」页:出发前清单(可勾选,自动保存在本机)、证件、支付、网络、安全、健康、礼仪

## 怎么用

**最简单**:解压后直接双击 `index.html`,用浏览器打开即可。所有内容都在本地,不需要联网。

**想像 App 一样安装、并保证离线缓存**:把整个文件夹放到支持 https 的静态托管上(例如 GitHub Pages),
用手机或电脑浏览器联网打开一次,之后即可离线使用,并可「添加到主屏幕」。

> 注意:`file://` 直接打开时不会注册离线缓存(因为不需要,文件本来就在本地)。

### 用 GitHub Pages 发布

1. 把本文件夹的全部文件提交到仓库 `main` 分支根目录。
2. 仓库 Settings → Pages → Source 选择 `main` 分支、`/ (root)`。
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

## 语音播报

使用浏览器内置的 Web Speech API,声音由设备系统提供:

- 点击板块右上角 **🔊 朗读** 听这一部分,或点 **朗读全文** 连续播放;播放时可暂停、继续、停止、调语速。
- 常用语表格里每一句都能点喇叭跟读。
- **离线语音**取决于系统是否安装了语音包。没有声音时,请到系统设置里下载中文(以及目的地语言)语音:
  - Android:系统「文字转语音」设置 → 语音引擎 → 安装语音数据
  - iPhone / iPad:设置 → 辅助功能 → 朗读内容 → 声音
  - Windows:设置 → 时间和语言 → 语音(或语言包中添加语音)
  - macOS:系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音

## 视频

视频不放进离线包(体积太大),而是提供 **YouTube / 哔哩哔哩的搜索链接**,联网时点击在新窗口打开,不会因为单个视频下架而失效。

## 加入你自己的照片

默认插画是用代码画的,不依赖任何图片文件。想换成真实照片:

1. 把照片放进 `images/` 文件夹(建议 1600 像素宽以内的 jpg)。
2. 在对应景点数组末尾加第 4 个元素,例如 `data-asia.js` 里:
   `['京都:伏见稻荷大社', 'torii', '说明文字……', 'images/fushimi.jpg']`
3. 把照片路径加入 `sw.js` 的 `ASSETS` 列表,并把 `CACHE` 的版本号加 1(如 `travel-guide-v2`),这样离线缓存也会包含照片。

照片加载失败时会自动退回插画。请使用你自己拍摄或有授权的照片。

## 添加新的目的地

在 `data-*.js` 里仿照现有条目新增一个对象即可(字段:`id`、`name`、`region`、`pal` 配色、`spots`、`food`、`phrases` 等)。
景点的第二项是插画类型,可选:

`mountain torii pagoda sakura skyline tower lantern spire terrace dome dunes pyramid andes balloon sails bridge castle canyon waterfall statue safari boat colosseum clock palm houses reef hanok market arch cathedral geyser stones`

新增文件后记得加入 `index.html` 的 script 列表和 `sw.js` 的 `ASSETS`。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架 |
| `style.css` | 样式(自动适配深色模式、手机与打印) |
| `art.js` | 离线 SVG 插画生成 |
| `data-asia.js` / `data-europe.js` / `data-world.js` | 目的地与通用指南内容 |
| `app.js` | 路由、渲染、语音播报 |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | 离线缓存与「添加到主屏幕」 |
